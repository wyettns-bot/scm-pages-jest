Software Configuration Management Demo

Static site deployed automatically with GitHub Actions + GitHub Pages

What happens on every push

  1. Checkout — the workflow pulls the latest commit.
  2. Lint — ESLint checks every JS file (semicolons required).
  3. Test — Jest runs unit tests on the page-load greeting function.
  4. Package — the public/ folder is bundled as a Pages artifact.
  5. Deploy — the artifact is published to GitHub Pages.

If linting or testing fails, packaging and deployment never run.
